# 🛍️ Responsive E-Commerce Landing Page

A modern and responsive **E-Commerce Landing Page** built using **HTML5, CSS3, and JavaScript** as part of my internship tasks.

---

## ✨ Features

- 📱 Fully Responsive Design
- 🌙 Dark / Light Theme Toggle
- 💾 Theme Persistence using LocalStorage
- 🍪 Cookie Consent Banner
- 🛒 Hero Section
- ⭐ Features Section
- 💰 Pricing Plans
- 📩 Contact Form
- 📱 Mobile-Friendly Layout

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage API
- Font Awesome
