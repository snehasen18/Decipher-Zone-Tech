# 📄 Interactive Resume Builder

A responsive client-side web application that helps users create, customize, preview, and export professional ATS-friendly resumes directly from the browser.

The application provides real-time resume generation, multiple templates, dynamic sections management, local data persistence, and PDF export functionality without requiring any backend.

---

## 🚀 Features

### 📝 Resume Creation
- Add personal information, education details, skills, projects, and work experience.
- Create professional resumes with structured sections.
- Update resume content dynamically.

### ⚡ Real-Time Preview
- Instant preview updates while editing information.
- Live synchronization between input fields and resume layout.
- Dynamic DOM manipulation for smooth user experience.

### 🎨 Multiple Resume Templates

**Template 1 - Classic Corporate**
- Clean single-column layout.
- Suitable for professional and academic resumes.

**Template 2 - Modern Sidebar**
- Modern two-column design.
- Separates profile details and professional information.

### 💾 Data Persistence
- Uses browser `localStorage` API.
- Automatically saves resume data.
- Prevents data loss after refreshing the browser.

### 📄 PDF Export
- Export resumes into A4 formatted PDF files.
- Implemented using `html2pdf.js`.
- Optimized print layout with custom CSS rules.

### 🌙 UI & Accessibility
- Dark mode support.
- Fully responsive design.
- Works smoothly on desktop, tablet, and mobile devices.
