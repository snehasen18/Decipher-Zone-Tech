# ⭐ Star Pattern Suite

A JavaScript-based interactive web application that generates multiple star and number patterns dynamically.

Users can select different patterns, adjust the grid size, customize characters, and see the output rendered instantly with a clean and responsive interface.

---

## 🚀 Features

- Generate **15 different star and number patterns**
- Interactive pattern selection
- Adjustable grid size using slider
- Custom character support
- Real-time pattern rendering
- Text-based pattern preview
- Dynamic DOM manipulation
- Responsive design for different screen sizes
- Multiple pattern variations with different logic

---

1. Clone this repository


2. Open the project folder

3. Open `index.html` in your browser

4. Select any pattern and customize the size or character
