# ⌨️ TypeMaster — Speed Typing Test

TypeMaster is a responsive client-side typing speed test application designed to measure and improve typing speed, accuracy, and consistency.

Built using HTML5, CSS3, and Vanilla JavaScript, the application provides real-time typing feedback, WPM calculation, accuracy tracking, mistake detection, countdown timer, and session-based high score storage.

---

## 🚀 Features

### ⚡ Real-Time Typing Analysis

- Calculates typing speed using Words Per Minute (WPM).
- Tracks typing accuracy percentage.
- Counts incorrect characters and typing mistakes.
- Provides instant performance feedback during the test.

### ⏱️ 60 Second Typing Challenge

- Timer starts automatically on first keystroke.
- Test completes automatically after 60 seconds.
- Displays final typing performance summary.

### 🎯 Character-Level Feedback

Each typed character receives visual feedback:

- 🟢 Correct character highlighting
- 🔴 Incorrect character highlighting
- 🔵 Current typing position indicator

### 🏆 Best Score Tracking

- Uses browser `sessionStorage` to save the highest WPM score.
- Maintains best performance during the active browser session.
- No backend or database required.

### 🔒 Typing Integrity

- Prevents copy-paste actions inside the typing area.
- Provides a fair typing test environment.

---

# 🛠️ Technology Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Application structure and UI elements |
| CSS3 | Responsive design, themes, layouts and animations |
| JavaScript ES6+ | Typing logic, timer handling, calculations and DOM updates |
